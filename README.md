# Raw Millets — Tisha & Vaishnavi

Premium static website prototype for Raw Millets, built with HTML, CSS and vanilla JavaScript.

## Live deployment

This project is ready for **GitHub Pages**. The publishing source can be set to the `main` branch and `/ (root)`.

## Files

- `index.html` — GitHub Pages entry point
- `firstprojectofRawmillets.html` — editable project HTML
- `firstprojectofRawmillets.css` — styling and responsive layout
- `firstprojectofRawmillets.js` — lightweight interactions
- `*.jpeg` — original project imagery

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## GitHub Pages

1. Create a public GitHub repository.
2. Upload the files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for the deployment and open the generated Pages URL.
